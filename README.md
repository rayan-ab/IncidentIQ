# IncidentIQ

IncidentIQ is an AI-assisted incident response and root-cause analysis web application.

## Main Features

- Incident description and log submission
- Log file upload
- AI-generated incident summary
- Timeline reconstruction
- Multiple root-cause hypotheses
- Evidence, assumptions, and uncertainties
- Immediate and long-term recommendations
- PDF report generation
- Incident history
- Dashboard statistics

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
- JSON
- ReportLab
